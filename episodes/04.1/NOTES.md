# 4.1 片外说明

这一页给看完默片的人。**不进视频。**

教材：[D2L 4.1 多层感知机](https://zh.d2l.ai/chapter_multilayer-perceptrons/mlp.html)

## 先说问题

线性一层 \(z=Wx+b\) 会吐负数。把这些数直接当「开着的隐单元」不行：有的方向你希望它干脆关掉。书里的 ReLU 就是这件事——小于 0 的写成 0，大于 0 的原样留下。关掉之后再映一次，才是输出 \(o\)。

默片只演这一件：同一颗光晕样本，先露出两根可负的针，负的那根被夹到零轴，再长出两根输出针。没有旁白。蓝、黄是点原来的组，不是模型猜的类。

## 画面里在干什么

1. **中文片头（4 秒）**：内容名称、章节号和一句极简讲解。
2. **两类点先停住**。亮蓝、黄是原始分组。
3. **圈住旅行者**，左侧固定写 \(x_1=0.80\)、\(x_2=0.60\)。这是这个点的坐标，不是权重。
4. **\(z=W_1x+b_1\)**：两根针按组上色。这一颗的预激活是 \(z_1=+1.200\)、\(z_2=-0.800\)。黄针朝下，就是「隐层输入可负」。
5. **公式换成 \(h=\mathrm{relu}(z)\)**，黄针收回零轴。屏幕上变成 \(h_1=1.200\)、\(h_2=0.000\)。正的那根没动；死掉的那根贡献是 0。
6. **\(o=W_2h+b_2\)**：从隐单元再做一次仿射。这一颗是 \(o_1=+1.300\)、\(o_2=-0.700\)。输出仍可负——ReLU 只夹了隐层，没有 softmax。

## 刻意没演

训练、反向传播、softmax、交叉熵。权重是写死的 \(2\times 2\) 矩阵，不是学来的。旅行者只是视觉身份，不是 3.1 那组带标签的点。
