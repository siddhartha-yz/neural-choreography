# 7.3 片外说明

这一页给看完默片的人。**不进视频。**

教材：[D2L 7.3 网络中的网络（NiN）](https://zh.d2l.ai/chapter_convolutional-modern/nin.html)

## 先说问题

卷积核看的是一小块邻域。有时候你只想在**同一个像素**上把通道搅一搅——那就是 \(1\times 1\)：核没有空间邻域，只是每个位置各自做一次全连接。NiN 把这件事当成逐像素的 MLP。

上一层如果还接全连接，空间结构会被拉平。NiN 的收尾换成全局平均汇聚：每张特征图压成一个数，直接当类别分数。没有旁白。

默片只演这一件：一张两通道的小图，过一次 \(1\times 1\)（高宽仍是 \(2\times 2\)），再 GAP 成三根 logit。权重是写死的，没训练。

## 画面里在干什么

1. **中文片头（4 秒）**：内容名称、章节号和一句极简讲解。
2. **两张 \(2\times 2\)**：\(X_1\)、\(X_2\) 先停住。数字写在格子上。
3. **一枚 \(1\times 1\)**：中间那张 \(3\times 2\) 的 \(W\) 就是它——三根输出通道、两根输入通道。右边空着三张同样 \(2\times 2\) 的 \(H_1,H_2,H_3\)。公式是 \(h=Wx\)。
4. **黄框同时罩住两张输入的左上格**。那一格的通道是 \(x_1=1\)、\(x_2=0\)，写在左侧固定口袋里，不是 \(x=[\,]\)。光晕圈住这个空间格。
5. **逐像素混合**：\(h=W\begin{bmatrix}1\\0\end{bmatrix}=\begin{bmatrix}1\\2\\0\end{bmatrix}\)，写进三张 \(H\) 的左上格。空间尺寸没变。其余格子随后补上，不再重讲一遍。
   - \(H_1=\begin{bmatrix}1&4\\4&7\end{bmatrix}\)
   - \(H_2=\begin{bmatrix}2&6\\4&8\end{bmatrix}\)
   - \(H_3=\begin{bmatrix}0&2\\4&6\end{bmatrix}\)
6. **公式换成一次** \(o=\mathrm{mean}(H)\)。黄框罩住整张 \(H_c\)，压成右边一个 \(1\times 1\)。三类是 \(o_1=4\)、\(o_2=5\)、\(o_3=3\)。光晕落到 \(o_1\)：旅行者跟的是自己那张图，不是最大的 \(o_2\)。最后一帧三张 \(H\) 和三根 \(o\) 都还在。

## 刻意没演

NiN 块里的两层 \(1\times 1\) 加 ReLU、softmax、训练、把 GAP 再接一层全连接。旅行者只是视觉身份：先是一个空间格，再是一根类别 logit。
