# 6.5 片外说明

## 先说问题

卷积会把局部模式写成一张还很大的图。往网络上面走，我们通常不需要每个像素都留着：既想对位置别那么敏感，又想让感受野变大。汇聚就是这件事——窗口里压成一个数，图变粗。

窗口里怎么压？两种常见答案：留下最大的（最大汇聚），或四格一起平均（平均汇聚）。都没有可学的权重。

默片只演这一件：同一张 \(4\times 4\) 的真数表，同一个 \(2\times 2\) 窗口，先取最大，再取平均。没有旁白。光晕跟着窗口里的赢家走。

## 画面里在干什么

1. **中文片头（4 秒）**：内容名称、章节号和一句极简讲解。
2. **左边 \(X\)**：一张 \(4\times 4\) 的数，格子只描边，数字写在格子上。
3. **右边两个空的 \(2\times 2\)**：格子和左边一样大，所以少一半边长就是分辨率掉了。
4. **黄框是 \(2\times 2\) 窗口**，从左上开始，按步幅 2 滑过四个位置。
5. **最大汇聚**：窗口里只有最大的那一格保持亮，光晕圈住它；其余三格变暗。这个最大值写进右边对应的输出格，格子上标 `max`。
   - \(\max(1,9,1,1)=9\)
   - \(\max(2,0,8,6)=8\)
   - \(\max(0,2,8,2)=8\)
   - \(\max(5,7,1,3)=7\)
6. **平均汇聚**：同一组窗口再走一遍。这一次窗口里四格都亮（大家都进平均），光晕仍停在刚才的赢家上。均值写进下面那个 \(2\times 2\)，格子上标 `avg`。四个均值是 \(3,4,3,4\)，都不是窗口里现成的某一格，所以不是「又挑了一个数」。
7. **停住**：左边 \(4\times 4\) 还在，右边 `max` 是 \(\begin{bmatrix}9&8\\8&7\end{bmatrix}\)，`avg` 是 \(\begin{bmatrix}3&4\\3&4\end{bmatrix}\)。

## 刻意没演

填充、非正方形窗口、多通道、把汇聚写成特殊卷积。步幅固定为 2，所以输出正好是 \(2\times 2\)。权重是没有的：汇聚层不训练。
