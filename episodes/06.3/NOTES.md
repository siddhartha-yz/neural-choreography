# 6.3 片外说明

这一页给看完默片的人。**不进视频。**

教材：[D2L 6.3 填充和步幅](https://zh.d2l.ai/chapter_convolutional-neural-networks/padding-and-strides.html)

## 先说问题

核在图上滑，输出格子的高宽不是随便画的。没有填充时，核会从边上掉下去，边缘那一格根本不存在；步幅大于 1 时，核跳着走，中间那些格也不会被写出来。书里的公式 \(\lfloor(n-k+2p)/s\rfloor+1\) 就是在数还剩下几格。

默片只演这一件：同一个 \(2\times 2\) 核，先不填、步幅 1，再给 \(X\) 围一圈 0，再把步幅改成 2。光晕圈住的是**一格输出**——它会先出现，再被步幅跳掉。没有旁白。核不训练。

## 画面里在干什么

1. **中文片头（4 秒）**：内容名称、章节号和一句极简讲解。
2. **\(X\) 是 \(3\times 3\)**，就是书 6.2 那组 \(0\ldots 8\)。上面的括号是 \(n=3\)。中间的 \(K=\begin{pmatrix}0&1\\2&3\end{pmatrix}\)，\(k=2\)。
3. **公式只出现一次**：`floor((n − k + 2p) / s) + 1`。后面变的是格子，不是又写一遍公式。
4. **\(p=0\), \(s=1\)**：黄框贴着走相邻的四格。右边输出是
   \(\begin{pmatrix}19&25\\37&43\end{pmatrix}\)，底下写 **\(2\times 2\)**。虚线圈在缺掉的那一格上：核还够不到顶边。
5. **一圈 0 围上来，\(p=1\)**：输出长成 **\(4\times 4\)**。虚线圈住的那一格变成 3，实线光晕亮起来——这格现在存在，因为窗口顶上两格是填充 0。整张输出是
   \(\begin{pmatrix}0&3&8&4\\9&19&25&10\\21&37&43&16\\6&7&8&0\end{pmatrix}\)。
6. **\(s=2\)**：核一次跳两格。输出只剩
   \(\begin{pmatrix}0&8\\21&43\end{pmatrix}\)，**\(2\times 2\)**。旅行者那一格（3）被跳过，光晕又变成空的虚线。

三个形状都对过 numpy：\((p,s)=(0,1)\to 2\times 2\)，\((1,1)\to 4\times 4\)，\((1,2)\to 2\times 2\)。

## 刻意没演

多通道、把核翻过来当真正卷积、训练。步幅在高宽上也不拆开——片里始终 \(s_h=s_w\)。
