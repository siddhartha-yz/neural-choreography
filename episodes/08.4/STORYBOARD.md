# 08.4 分镜提案：当前输入相同，为什么答案不同？

状态：**分镜待评审，尚未制作成动画**。现有 rnn-flow 是被重新审视的旧样片，不能当作本分镜的实现。

## 观众要得到什么

问题：最后看到的都是问号，怎样答出最早看到的是 A 还是 B？

看完应能预测：保留旧状态时两条序列可以作出不同回答；在回答前清空状态，两条序列就失去区别；交换最早的输入，最后的选择也应交换。

这里讲「状态把过去带进当前判断」。状态空间收缩、梯度、训练与语言预测不作为这一集的主线。

## 画面中的约定

两行分别播放 `A → · → ?` 与 `B → · → ?`。A 与 B 的输入卡使用不同形状并辅以蓝、橙色；中间圆点只表示占位输入。问号是询问最早符号，不是语言模型的下一个词预测。

状态用一条固定宽度的水平刻度和一个可移动指针表示。中心是零；左右位置是同一个标量状态的负正值，不表示时间。蓝、橙仅区分两条序列，不能把颜色当作答案传入计算。符号历史随后淡出，读取答案只能使用当时保留的状态。

每行只有一个更新器，在同一位置被重复使用。先让它处理三次输入，必要时才短暂展开成三个位置，并明确这表示时间上的复用。

## 可复算的玩具 RNN

这是**手工设定权重的教学模型**，不是训练好的字符模型。状态是一维，便于建立图形含义：

- h₀=0；A 编码为 +1，B 编码为 −1，占位符与问号都编码为 0。
- 每一步使用相同的更新 hₜ=tanh(0.8hₜ₋₁+xₜ)。
- 最后只读状态：h>0 选 A，h<0 选 B，h=0 显示未决问号。
- 两条序列的状态绝对值相同、符号相反。清空对照只把问号前的 h₂ 改成零；当前输入、权重、读出完全不变。

下面代码可复算关键落点，不要求把数值都写进片内：

```python
from math import tanh
for first in (1.0, -1.0):
    h = 0.0
    for x in (first, 0.0, 0.0):
        h = tanh(0.8 * h + x)
        print(h)
assert tanh(0.8 * 0.0 + 0.0) == 0.0
```

显示比例固定，不把两行分别归一化。指针长度和位置随真实状态变化。状态刻度始终同样大，不能画成历史符号依次装入一个越来越大的盒子。正负读出在这个模型中是人为约定，不能推广为一般隐状态分量有固定语义。

此玩具模型独立于现有二维模型 `zanim_scenes/models/ep_08_4.py`；制作新分镜时应单独实现，保留旧计算作历史对照。当前只完成了分镜与示意图，尚未切换渲染入口。
