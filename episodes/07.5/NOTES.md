# 7.5 片外说明

这一页给看完默片的人。**不进视频。**

教材：[D2L 7.5 批量规范化](https://zh.d2l.ai/chapter_convolutional-modern/batch-norm.html)

## 先说问题

深层网络中间层的数会漂：这一批偏大，下一批偏小，优化器每层都得重新找步长。批量规范化的办法是：就拿**这一小批**点，减掉它们的均值，除掉它们的标准差，先做成均值 0、方差 1。然后再用 \(\gamma\) 和 \(\beta\) 把尺度和位置交还给模型。

片里的 \(\gamma,\beta\) 是写死的，不是学来的。先让 \(\gamma=1\)、\(\beta=0\)，旅行者停在标准化后的 0 上——它本来就是这批的均值。然后再把 \(\gamma,\beta\) 挪一下，整批一起被拉长、抬高。

默片只演这一件：五根针，先对中，再按 \(\sigma\) 缩放，再被 \(\gamma,\beta\) 挪走。没有旁白。没有 4-D 张量仪表盘。

## 画面里在干什么

1. **中文片头（4 秒）**：内容名称、章节号和一句极简讲解。
2. **五根针**：原始特征 \(x=(0.400,\,1.200,\,2.000,\,2.800,\,3.600)\)。光晕那根是旅行者，高度正好是这批的均值。
3. **公式只写一次** \(y=\gamma((x-\mu)/\sigma)+\beta\)。黄线标 \(\mu=2.000\)，穿过旅行者的针尖。
4. **减均值**：五根一起往下掉 \(\mu\)。旅行者落到 0；有的针穿到零轴下面，就是「减完以后可负」。
5. **除以 \(\sigma\)**：\(\sigma=1.131\) 是这五根对 \(\mu\) 的均方根，不是另一组数。除完 \(\hat x=(-1.414,\,-0.707,\,0.000,\,0.707,\,1.414)\)。旅行者仍在 0。
6. **\(\gamma=1.00,\ \beta=0.00\)**：还没拉尺度。旅行者停在标准化的 0。
7. **短短的 \(\gamma,\beta\) 平移**：\(\gamma=1.50,\ \beta=+0.40\)。输出 \(y=(-1.721,\,-0.661,\,0.400,\,1.461,\,2.521)\)。旅行者到 \(0.400\)。权重不训练。

## 刻意没演

训练 \(\gamma,\beta\)、移动平均、预测模式、卷积通道上的 \(m\cdot p\cdot q\)、\(\varepsilon\) 垫底。下一集若走 7.6，才轮到残差捷径。
