# 创作约定：一整串 D2L 神经网络动画作品

目标是可连续欣赏的数学动态艺术作品。观众可以纯粹观看形态、运动与结构，不需要跟着提问、字幕或数值完成一节课。本约定替代此前的教学分镜要求，也替代最初的固定短片模板。

## 整体形式

章节是同一部作品中的段落。上一段的形状、轨迹、颜色或运动方向成为下一段的起点；避免每集重新开场、清屏、总结。保留 D2L 的内容顺序，以相邻章节的串联片段验证整体风格，再扩展成全片。

已发布的 Zanim 完整版为静音，1920×1080、60 fps、H.264。时长服从运动编排和观看节奏，不设 20–45 秒硬限制。画面本身应有节奏；后续专属配乐按用户指定的钢琴夜曲方向制作，先用两分钟样片审听，再扩展全片，制作记录见 [配乐草稿](SOUNDTRACK.md)。音乐乐句可以跨章节延续，不用每段标题都触发新循环。MP4 放本地输出或 Release，不进 Git 历史。

## 视觉语言

借鉴 3Blue1Brown 的干净几何、克制配色、细线条、清晰层次和连续变换。黑底为主，蓝与青作为基础，金、橙、紫用于运动方向与层次的变化。颜色可以有艺术节奏，但同一段中对象的身份应可追踪。

画面的主体是群体结构：点群、网格、曲面、向量场、连接与流动。可采用扩散、汇聚、折叠、展开、旋转、剪切、穿越和交织。多组动作由同一个结构关联起来；主运动、次级流动和背景变化有不同速度与强弱。

在密与疏、快与慢、收紧与释放之间建立节奏。保留适量空白，但不让一颗小球、一根柱子或一块小网格长期占据空舞台。多动态不等于所有对象随机抖动。

二维和三维按构图、空间感与转场需要选择。镜头、投影、景深与路径设计为整体观看服务；不统一套立体盒子或坐标系。画面可以有抽象段落，不要求每个装饰都完成教学任务。

## 文字

保留「中文主题 · 章节号」与一句极简中文提示，放在不争夺视觉主体的位置。标识自然过渡，不强制四秒片头。

不使用说明侧栏、长段字幕、预测题、教学卡片和逐步公式讲解。公式仅在确实构成视觉主体时使用，不能变成固定占据画面的信息栏。默认不显示中间数值表和计算读数。

## 数学与艺术处理

数据与机制提供结构基础；空间投影、连续插值、轨迹速度、形态转场及配色承担艺术编排。二者的边界写在源码与制作说明中，不把整段免责声明塞进画面。

涉及实际递推、梯度或门控时验证其端点与关系。艺术插值不是额外的模型时间步；为构图设计的转场不冒充数学等价。未训练模型不声称已学会真实任务。

## 制作与审看

先选相邻章节，确定贯穿它们的运动母题与形状交接，再实现完整动态样片。以连续观看判断：是否流畅、耐看、丰富、有节奏，章节交界是否割裂。静态封面或代码通过不能替代审看。

分别记录艺术反馈、数学检查与工程验证。艺术质量由实际观看反馈决定；不得用测试数量宣布审美过关。旧 49 集技术迁移完成，不代表已成为一部统一的连续作品。

当前按倒序补做较早章节，最终仍正序播放。最新范围、时间线与艺术反馈见 [连续样片制作记录](CONTINUOUS_STUDY.md)。当前 Zanim 完整版已覆盖原目录全部 49 段，并按正序输出成片；本轮先完成现有作品，替代引擎的独立试验不影响此版本。新增段落的艺术反馈与成片导出状态分别记录。

结构辨识是作品约束：GRU 的重置与互补更新、LSTM 的独立记忆主干与三门要落实为不同的连接与运动，不能只换标题或配色。必要门标签可以保留，避免为了去文字而抹去机制特征。
